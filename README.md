# CODSOFT
This repository contains three Java-based mini projects designed to strengthen core Java programming concepts and improve logical problem-solving skills.

TASK 1: 
The Currency Converter is a simple and efficient application that converts one currency into another using current exchange rates. It provides quick and accurate currency conversion and helps users understand real-world financial calculations.

TASK 2: 
Student Grade Calculation is a simple application that calculates a student’s total marks, average, grade, and pass/fail status based on the entered subject marks. This project is developed to understand basic programming concepts such as conditional statements, loops, arithmetic operations, and user input handling.

TASK 3: 
This is a Java-based Number Guessing Game where the system generates a random number between 1 and 100, and the player must guess it within a limited number of attempts. The game provides helpful hints like ‘Too High’ or ‘Too Low’ after each guess and calculates a score based on performance. This project is created to practice core Java concepts such as loops, conditional statements, user input handling, and random number generation.
